Una función regular tiene su propio contexto de ejecución. 
Eso significa que crea su propio this, su propio objeto arguments 
y puede comportarse como constructor. En la práctica, esto permite 
que se use dentro de objetos cuando se necesita acceder correctamente 
a las propiedades del mismo objeto, que se pueda utilizar con la palabra 
clave new para crear instancias, y que pueda recibir una cantidad indefinida 
de parámetros sin declararlos explícitamente. Además, las funciones regulares 
declaradas pueden invocarse antes de estar escritas en el código debido al hoisting.
En cambio, una función de flecha no crea su propio contexto. No tiene su propio 
this, sino que toma el this del entorno donde fue definida. En la práctica, 
esto significa que no sirve como método tradicional dentro de objetos cuando 
se necesita que this apunte al objeto mismo. Tampoco puede utilizarse como constructor, 
por lo que no se pueden crear instancias con new. No dispone del objeto arguments, por lo 
que para manejar múltiples parámetros se debe usar el operador rest. Además, no se puede 
ejecutar antes de su declaración cuando está definida con let o const.

En términos prácticos:

Si necesitas crear objetos, usar this dinámico o definir métodos formales, se utiliza función regular.

Si necesitas una función más corta, mantener el contexto externo y usarla como 
callback o función auxiliar, se utiliza función de flecha.
